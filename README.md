# 🎯 Number Guessing Game (Python)

A simple and beginner-friendly Number Guessing Game built using Python.

In this game, the computer randomly selects a number between 1 and 100, and the player tries to guess it correctly using hints.

# 📌 Features

✅ Random number generation (1–100)  
✅ Higher / Lower hints  
✅ Attempt counter  
✅ Guess history tracking  
✅ Input validation (error handling)  
✅ Loop-based gameplay  
✅ Beginner-friendly Python project  

# 🛠 Technologies Used

- Python 3
- random module
- while loop
- if-elif-else conditions
- lists
- try-except (error handling)

# 🎮 How It Works

- Computer selects a random number between 1 and 100  
- User keeps guessing  
- Program gives hints:  
  - 📈 Higher number please  
  - 📉 Lower number please  
- Game continues until correct answer  
- Tracks total attempts and guess history
